# Система управления банковскими картами

Запуск проекта с Docker

1. Сначала создайте локальный `.env` файл на основе .env.example в корне проекта
2. Выполните команду docker-compose up --build
3. Документация Swagger http://localhost:8080/swagger-ui/index.html#/
4. По умолчанию сгенерируется администратор с username: root, password: root

Дополнительно / Вспомогательные классы (не указанные в ТЗ):

- `src/main/java/com/example/bankcards/entity/filter/filter_item (Filter Item)` – отдельный фильтр по конкретному
  полю/группе полей. Реализует интерфейс с методами `isApplicable()` и `apply()`. Пример: фильтр по статусу карты (
  `UserCardStatusFilter`).

- `src/main/java/com/example/bankcards/entity/filter/builder (Filter Builder)` – собирает все фильтры по интерфейсу в
  цепочку и создает готовую `Specification`. Используется в вызове репозитория: `findAll(specification, pageable)`.
  Скрывает внутреннюю логику применения фильтров, упрощая использование.

- `src/main/java/com/example/bankcards/config/filter/TraceIdFilter.java` – фильтр для генерации и передачи `X-Trace-Id`.
    - При каждом HTTP-запросе, в случае отсутствия, создаёт уникальный `traceId` .
    - Передаёт его в заголовке `X-Trace-Id` при вызове других микросервисов.
    - Используется для отслеживания цепочки запросов и автоматического логирования ошибок.

- `src/main/java/com/example/bankcards/mapper` – мапперы для трансформации сущностей в DTO и обратно.
    - Используются для преобразования данных между слоями приложения.

- `src/main/java/com/example/bankcards/policy` – политики выполнения действий.
    - Служат для реализации бизнес-правил и условий, которые должны быть выполнены перед выполнением операции.

Возможные проблемы:

- В некоторых запросах нужно передавать `idempotencyKey`.  
  При повторных запросах с тем же `idempotencyKey` может произойти одно из двух:
    1. Ошибка, если при том же `idempotencyKey` и разных входных данных
    2. Ответ с кодом 200, но логика запроса будет пропущена (так как операция уже была выполнена ранее)

- Ошибка может возникнуть, если истёк JWT-токен.  
  В этом случае необходимо предварительно разлогиниться, получить новый токен и повторить запрос.

<h2>📝 Описание задачи</h2>

  <ul>
    <li>Создание и управление картами</li>
    <li>Просмотр карт</li>
